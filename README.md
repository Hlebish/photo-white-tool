# Фото деталей — белый фон 640×480

Статический GitHub Pages сайт: удаляет фон через Transformers.js/RMBG-1.4, заменяет его белым и экспортирует JPG 640×480.

Важно: для Transformers.js 3.x вход в background-removal передаётся как `File/Blob`, а не `HTMLImageElement`.
