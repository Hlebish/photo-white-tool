# Photo White Tool V4

Специализированный браузерный обработчик фото автомобильных деталей.

## Что внутри
- BiRefNet Lite ONNX для удаления фона.
- Автоматическая очистка мелких независимых пятен.
- Сохранение крупнейшего связного объекта.
- Опциональный Swin2SR x2 перед финальным уменьшением.
- Высококачественное масштабирование на холсте 640×480.
- JPG 100% или PNG без потерь.
- Локальная обработка в браузере, без сервера.

## Запуск на GitHub Pages
1. Создай публичный репозиторий.
2. Загрузи `index.html`.
3. Settings → Pages → Deploy from branch → `main` → `/root`.
4. Открой выданную GitHub Pages ссылку.

Модели загружаются из Hugging Face при первом запуске и затем кэшируются браузером.
