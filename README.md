# Фото деталей — белый фон 640×480

Статический сайт для обработки фотографий автомобильных деталей прямо в браузере.

- удаление фона: RMBG-1.4;
- белый фон #FFFFFF;
- сохранение пропорций и автоматическое кадрирование;
- итоговый размер 640×480;
- JPG с качеством 98% или PNG без потерь;
- опциональное AI-улучшение через `Xenova/swin2SR-classical-sr-x2-64`;
- AI-улучшение не используется для маски/контура детали: исходная альфа-маска сохраняется отдельно и применяется после улучшения RGB;
- обработка выполняется в браузере.

Swin2SR — классическая super-resolution модель, а не генеративная модель изменения содержимого. Тем не менее любое AI-улучшение может немного менять микротекстуру, поэтому для максимальной консервативности галочку AI-улучшения можно отключить.
