# Photo White Tool V5

Исправленная версия после ошибки `drawImage`.

Что изменено:
- больше нет передачи обычного JS-объекта в `drawImage`;
- исходник читается через `RawImage.read(file)`;
- BiRefNet-ONNX используется как основной сегментатор, Lite — как fallback;
- WebGPU → WASM fallback;
- интерфейс адаптивный и не сжимает блок загрузки;
- JPG 100% / PNG;
- результат 640×480;
- опциональный Swin2SR x2;
- ластик для удаления мусора уже на готовом результате.

Важно: первый запуск модели может быть долгим.
