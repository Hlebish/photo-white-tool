# Фото деталей — белый фон 640×480

Небольшой статический сайт для подготовки фотографий автомобильных деталей.

## Что делает

1. Принимает одну или несколько фотографий.
2. Удаляет фон при помощи RMBG-1.4 в браузере.
3. Заливает чистый белый фон.
4. Автоматически находит границы детали и аккуратно центрирует её.
5. Экспортирует JPG строго 640×480.
6. Можно скачать отдельные изображения или весь результат одним ZIP.

## Запуск на GitHub Pages

Загрузи `index.html` и `README.md` в репозиторий и включи GitHub Pages для ветки `main` / папки `/root`.

Это статический сайт — Node.js и Firebase не нужны.

## Важно

AI-модель загружается из Hugging Face при первом запуске и затем кэшируется браузером. Самые фотографии обрабатываются локально в браузере и не отправляются на сервер приложения.

Проект использует Transformers.js и модель BRIA RMBG-1.4. Перед коммерческим использованием проверь актуальные условия лицензии модели.
